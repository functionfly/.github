# Agent Marketplace

Browse and deploy pre-built agents for common use cases.

## Categories

- **Data & Analytics** - Data processing, reporting, visualization
- **Developer Tools** - Code review, testing, deployment
- **Customer Support** - Chat, ticket management, FAQs
- **Automation** - Workflows, scheduling, integrations

## Using Marketplace Agents

1. Go to **Dashboard → Agents → Marketplace**
2. Browse categories or search
3. Click **Deploy** to add to your account
4. Configure settings and integrate

## Publishing Your Agent

1. Build your agent with the SDK
2. Test thoroughly
3. Submit to marketplace for review
4. Set pricing (free or paid)
