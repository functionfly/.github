# Agents

FunctionFly Agents are autonomous AI agents that can execute tasks, use tools, and interact with your functions.

## Features

- **Multi-step reasoning** - Agents can break down complex tasks
- **Tool use** - Access to functions, APIs, and external services
- **Memory** - Persistent context across conversations
- **Behavioral policies** - Configurable safety and behavior rules

## Creating an Agent

```bash
# Initialize a new agent
ff agent init my-agent

# Configure in dashboard or via API
```
